# Module Documentation Templates

This directory contains templates for documenting new modules. Copy these files when creating a new module directory.

## Files

- `README.md` - Module overview template
- `implementation-plan.md` - Implementation plan template
- `api-flows.md` - API documentation template
- `ui-flows.md` - UI flow documentation template
- `database-schema.md` - Database schema template
- `testing-plan.md` - Testing plan template

## Usage

When creating a new module:

1. Create a directory in `implementation_plan_flows/` with your module name
2. Copy all template files from this directory
3. Fill in the templates with your module-specific information
4. Keep the documentation updated as the module evolves
